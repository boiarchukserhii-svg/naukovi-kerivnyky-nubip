# Наукові керівники аспірантів НУБіП України

Оболонка застосунку в світлій синьо-білій палітрі. Поступове наповнення від 2026 до 2016 року.

## Запуск

[Відкрити застосунок](https://boiarchukserhii-svg.github.io/naukovi-kerivnyky-nubip/)

Статичний застосунок - збірка та встановлення залежностей не потрібні. GitHub Pages: main, корінь репозиторію.

## Дані

У застосунку «Аспіранти» збережіть копію реєстру, потім імпортуйте JSON через «Імпортувати дані». Також підтримуються повні резервні копії попередньої автономної версії «Наукові школи НУБіП».

У репозиторії немає реальних персональних даних. Вигаданий приклад завантажується лише за кнопкою користувача й явно позначається. Робочі записи зберігаються в браузері, без серверної синхронізації. Резервні JSON-копії не додавайте в репозиторій.

## Розділи

- Огляд.
- Керівники та персональні картки.
- Наукові школи.
- Захисти та ради.
- Навантаження.
- Адміністративна аналітика якості даних.

Історичні вибірки за строками навчання є попередніми. Поточний керівник і статус не відновлюються автоматично на минулу дату. Захисти та години вносяться окремо. Методика результативності й штрафних балів не затверджена.

Окремі серверні ролі доступу ще не реалізовані. Не публікуйте тут приватний реєстр і не використовуйте оболонку як спільну захищену базу.

## Структура

`index.html` - оболонка. `style.css` - оформлення. `app.js` - локальна логіка. `icon.svg` - власна нейтральна позначка, без офіційного герба.
